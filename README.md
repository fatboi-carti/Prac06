# Реакция на подключение устройства

При подключении флешки список USB-устройств сразу изменится. Без перезапуска ПК.

Вывод программы до подключения флешки:

```
  - USB-устройство ввода
  - Универсальный USB-концентратор
  - Корневой USB-концентратор (USB 3.0)
```

После подключения флешки:

```
  - USB-устройство ввода
  - Универсальный USB-концентратор
  - Корневой USB-концентратор (USB 3.0)
  - Запоминающее устройство для USB
  - USB DISK 2.0 USB Device
```

Сразу прибавилось одно устройство.

# Вопросы на осмысление

1. Сведения об устройствах Windows получает как раз через WMI. Не всегда нужно обращаться непосредственно к самому устройству.
2. Если сразу включать все пакеты в стандартный набор, то он будет весить очень много. Поэтому кому нужно, тот подключит.
3. Изменение списка USB-устройств без перезапуска подтверждает динамичность данных WMI. Он постоянно предоставляет актуальные сведения.
4. Наша программа и Диспетчер устройств Windows используют WMI для получения данных об устройствах компьютера.
