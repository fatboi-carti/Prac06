# Информация о процессоре

Предположение: 4 физ. ядра, 8 логич. ядра
Результат программы: 4 физ. ядра, 8 логич. ядра

Результаты совпали с предположением и с тем, что мы видели ранее в других программах.
Физическое ядро может разделяться на несколько логических, чтобы эффективней работать в параллельных процессах.
